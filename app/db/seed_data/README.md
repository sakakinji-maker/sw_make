# 가상 데이터 (11주차, 전원)

실제 개인정보·실제 매장 자료는 사용하지 않습니다. 생성형 AI로 만들고, 사용한 프롬프트는 `docs/data_prompts.md`에 남깁니다.

| 파일 | 내용 | 수량 | 담당 |
| --- | --- | --- | --- |
| `stores.json` | 매장 + 메뉴 | 매장 2, 메뉴 10~15/매장 | 한재형 |
| `customers.json` | 고객 | 30 | 한재형 |
| `reservations.json` | 예약 (상태 골고루) | 50 | 한재형 |
| `faqs.json` | FAQ | 10/매장 | 정회성 |
| `inquiries.json` | 문의 (가격 10, 영업시간 10, 근거 밖 10) | 30 | 정회성 |
| `contents.json` | 채널별 홍보 문구 예시 | 채널당 5 | 전지호 |

`python -m app.db.seed`가 이 폴더의 JSON을 읽어 DB에 넣습니다. (적재 코드: 정회성, 11주차)
