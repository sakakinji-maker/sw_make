# 생성형 AI API 선정 및 키 발급 가이드

작성: 정회성 · 10주차 · **결정 기한: 10/30(금) 팀 회의**

## 1. 결론부터

- 개발과 테스트는 **Mock AI**(`AI_PROVIDER=mock`)로 한다. 실제 API는 F-03·F-04 동작 확인, 검증 실험(13주차), 시연 때만 쓴다.
- 실제 API 키는 **정회성 1명만** 발급해 관리한다. 비용과 키 유출 위험을 한곳으로 모으기 위해서다.
- 어떤 API를 고르든 `app/adapters/ai/`에 Adapter 클래스 하나만 추가하면 된다(NF-03). 그래서 이번 선택은 "나중에 바꿀 수 없는 결정"이 아니다.

### 품질 비교 방법 (각 후보별 10분)

각 서비스의 웹 테스트 화면(Playground 등)에서 아래 두 프롬프트를 그대로 넣고 결과를 비교한다.

**① 문의 답변 (F-03): 근거 밖 질문을 지어내지 않는지 확인**

```
[시스템] 당신은 소상공인 매장의 고객 문의 답변을 돕는 도우미입니다. 반드시 아래 매장 정보·메뉴·FAQ만
근거로 답하세요. 근거에 없는 내용은 '매장에 직접 문의해 주세요'라고 답하세요.

[매장] 온기 카페, 영업시간 09:00~21:00, 휴무일 월, 연락처 02-000-0000
[메뉴]
- 아메리카노: 4,500원
- 카페라떼: 5,000원
[FAQ]
- Q: 주차 되나요? / A: 건물 뒤편에 2대 주차 가능합니다.
[고객 문의]
화요일 저녁 8시에 가도 되나요? 그리고 콜드브루 있나요? 가격도 알려주세요.
```

좋은 답: 화요일 20시는 영업 중이라고 답하고, 콜드브루는 메뉴에 없으니 매장에 문의하라고 안내한다. 가격을 지어내면 탈락.

**② 홍보 문구 (F-04): 형식 규칙을 지키는지 확인**

```
인스타그램 게시글을 작성하세요. 첫 문장에서 시선을 끌고 끝에 해시태그를 붙이세요.
- 홍보 대상: 카페라떼 (5,000원)
- 키워드: 가을, 따뜻함
- 길이: 50~300자
- 해시태그: 3~10개
- 어조: 친근하고 감각적인 말투, 이모지 1~3개
```

좋은 답: 300자 이내, 해시태그 3~10개, 가격 5,000원 정확.

## 5. 키 발급 후 할 일

1. 공식 사이트에서 키를 발급받는다. 사용 한도(월 예산 상한) 설정 메뉴가 있으면 **반드시 낮게 설정**한다.
2. 프로젝트 폴더의 `.env`에만 넣는다.
   ```
   AI_PROVIDER=external
   AI_API_KEY=발급받은_키
   ```
3. **절대 하지 말 것**: 코드에 키 직접 쓰기, Git 커밋, 카카오톡·디스코드에 키 붙여넣기, 스크린샷에 키 노출.
4. 키가 유출됐다고 의심되면 즉시 해당 사이트에서 키를 삭제하고 새로 발급한다.
5. 팀원은 실제 키 없이 `AI_PROVIDER=mock`으로 개발한다. 실제 API 결과가 필요하면 정회성에게 요청하거나 시연용 PC에서 확인한다.
6. 사용 내역은 `docs/ai_usage_log.md`에 기록한다.
