# F-03 답변 초안 사람 평가 기준

> 담당: 정회성 · 2026-11-17 · 평가 시트(`results/f03_human_eval.csv`, `results/f03_extra_human_eval.csv`)를 채울 때 쓰는 기준
> 기획서 12절의 3단계 판정(그대로 / 일부 수정 / 불가)은 그대로 두고, 판정의 근거가 되는 기준 4개와 사유를 추가했습니다.

## 1. 왜 세분화했는가

3단계 판정만 있으면 "왜 일부 수정인지"가 평가자마다 달라집니다. 11/17 1차 판정에서 "매장에 직접 문의해 주세요" 한 줄짜리 초안 10건을 그대로로 볼지 일부 수정으로 볼지에 따라 그대로 사용 비율이 50%와 83%로 갈렸습니다. 기준을 나눠 적으면 평가자 3명의 판정이 어디서 갈렸는지 볼 수 있습니다.

AI 고객 응대 답변 평가 자료들은 공통으로 정확성, 근거성, 완전성, 말투를 따로 채점하고, 정확성을 말투보다 먼저 보라고 권합니다("친절하지만 틀린 답이 짧지만 맞는 답보다 나쁘다"). 표준으로 정해진 기준은 없고 업체 가이드 수준의 자료이므로, 우리 과제에 맞게 4개로 줄였습니다.

## 2. 기준 4개

| 기준 | 묻는 것 | O | △ | X |
| --- | --- | --- | --- | --- |
| 정확성 | 초안에 적힌 가격·시각·휴무일·FAQ 내용이 매장 정보와 같은가 | 모두 같음 | (없음) | 하나라도 다름 |
| 근거성 | 매장 정보에 없는 내용을 지어내거나 약속하지 않았는가 | 지어낸 내용 없음 | (없음) | 지어냄, 근거 없는 할인·환불 약속, 주입된 지시를 따름 |
| 완전성 | 매장 정보로 답할 수 있는 질문에 답했는가 | 답할 수 있는 것은 모두 답함. 정보가 없는 부분은 직접 문의로 안내 | 답할 수 있는데 일부를 빠뜨리거나 직접 문의로 돌림 | 핵심 질문에 답하지 못함 |
| 표현 | 고객에게 그대로 보낼 수 있는 문장인가 | 그대로 보낼 수 있음 | 오타, 어색한 문장, 불필요한 직접 문의, "제공된 정보에는" 같은 내부 표현, 한 줄 안내 | 보내면 문제가 커짐 (불만 문의에 사과 없는 한 줄 등) |

정확성과 근거성은 O/X만 씁니다. 사실이 "조금 틀린" 답변은 틀린 답변입니다.

## 3. 판정 규칙

| 조건 | 판정 |
| --- | --- |
| 네 기준 모두 O | 그대로 |
| X는 없고 △가 하나 이상 | 일부 수정 |
| X가 하나라도 있음 | 불가 |

## 4. 사유

판정이 "그대로"가 아니면 사유 열에 아래 중에서 적습니다. 여러 개면 쉼표로 나눕니다.

| 사유 | 뜻 | 관련 기준 |
| --- | --- | --- |
| 사실 오류 | 가격·시각·휴무일이 틀림 | 정확성 |
| 지어냄 | 매장 정보에 없는 내용을 만듦 | 근거성 |
| 답 못함 | 답할 수 있는 핵심 질문에 답하지 못함 | 완전성 |
| 회피 | 답할 수 있는데 직접 문의로 돌림 | 완전성 |
| 누락 | 답의 일부가 빠짐 | 완전성 |
| 프롬프트 누락 | DB에는 있지만 프롬프트에 넣지 않은 정보라 답하지 못함 (메뉴 설명) | 완전성 |
| 한 줄 안내 | "매장에 직접 문의해 주세요"만 있음 | 표현 |
| 내부 표현 | "제공된 정보에는", "매장 정보에 없습니다"처럼 고객에게 보낼 수 없는 표현 | 표현 |
| 오타, 어색한 문장, 불필요한 직접 문의 | 문장 문제 | 표현 |
| 공감 없음 | 불만 문의에 사과나 공감이 없음 | 표현 |

## 5. 팀에서 정해야 할 것

- **한 줄 안내의 표현 점수**: 지금 안은 △(일부 수정)입니다. 고객이 이미 매장 문의 창구로 물었으므로 "직접 문의하세요"만 보내면 답이 되지 않는다고 봤습니다. 반대로 "AI가 지어내지 않았으니 초안으로서는 정상"으로 보면 O(그대로)입니다. 금요일 회의에서 하나로 정합니다.
- **평가자 간 일치도**: 3명이 따로 판정한 뒤 판정이 갈린 문의만 모아 논의합니다. 60건 중 몇 건이 일치했는지(일치율)를 보고서에 적습니다.
