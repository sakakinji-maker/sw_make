# 유스케이스 다이어그램

> 프로젝트: 소상공인용 AI 마케팅·고객응대 통합 지원 시스템  
> 팀: 신창섭 | 작성일: 2026-11-03 | 담당: 한재형·정회성

---

## 1. 행위자 (Actors)

| 행위자 | 설명 |
|--------|------|
| **점주** | 시스템을 운영하는 소상공인. 매장 정보 관리, 예약 관리, 마케팅 수행 |
| **고객** | 매장에 문의하거나 예약을 요청하는 사람 |
| **AI API** | 외부 생성형 AI 서비스 (OpenAI / Claude). 문의 답변 및 홍보 문구 생성에 활용 |

---

## 2. 유스케이스 목록

### 2-1. 매장·메뉴·FAQ 관리 (F-01)

```
점주 ──► UC-01 매장 정보 등록·수정
점주 ──► UC-02 메뉴 추가
점주 ──► UC-03 메뉴 수정·삭제
점주 ──► UC-04 FAQ 등록
점주 ──► UC-05 FAQ 검색
```

| UC | 유스케이스 | 사전 조건 | 정상 흐름 | 예외 |
|----|-----------|----------|----------|------|
| UC-01 | 매장 정보 등록·수정 | 점주 로그인 | 매장명·주소·전화·영업시간 입력 → DB 저장 → 확인 출력 | 필수 항목 누락 시 오류 메시지 |
| UC-02 | 메뉴 추가 | 매장 등록 완료 | 메뉴명·가격·설명 입력 → DB 저장 → 목록 갱신 | 가격 음수 입력 시 오류 |
| UC-03 | 메뉴 수정·삭제 | 메뉴 존재 | 메뉴 선택 → 항목 수정 또는 삭제 확인 → DB 반영 | 존재하지 않는 메뉴 선택 시 오류 |
| UC-04 | FAQ 등록 | 매장 등록 완료 | 질문·답변 입력 → DB 저장 | 빈 입력 시 오류 |
| UC-05 | FAQ 검색 | FAQ 1건 이상 존재 | 키워드 입력 → 일치 항목 출력 | 결과 없으면 "없음" 안내 |

### 2-2. 예약·고객 관리 (F-02)

```
고객  ──► UC-06 예약 요청
점주  ──► UC-07 예약 확정
점주  ──► UC-08 예약 완료 처리
점주  ──► UC-09 예약 취소
점주  ──► UC-10 고객 이력 조회
```

| UC | 유스케이스 | 상태 전이 | 정상 흐름 |
|----|-----------|----------|----------|
| UC-06 | 예약 요청 | → **대기(Pending)** | 고객명·전화·일시·인원 입력 → 예약 생성 |
| UC-07 | 예약 확정 | 대기 → **확정(Confirmed)** | 예약 선택 → confirm() → 상태 변경 |
| UC-08 | 예약 완료 | 확정 → **완료(Completed)** | 방문 후 완료 처리 → complete() |
| UC-09 | 예약 취소 | 대기/확정 → **취소(Cancelled)** | 취소 사유 입력 → cancel() |
| UC-10 | 고객 이력 조회 | — | 전화번호 검색 → 방문 횟수·예약 이력 출력 |

**상태 전이 다이어그램**

```
[생성] ──► 대기(Pending)
              │
              ├──► 확정(Confirmed) ──► 완료(Completed)
              │         │
              └─────────┴──────────► 취소(Cancelled)
```

### 2-3. AI 고객 문의 응대 (F-03)

```
고객   ──► UC-11 문의 질문 입력
AI API ──► UC-12 AI 답변 생성  《include》UC-11
점주   ──► UC-13 답변 DB 대조 검증  《include》UC-12
```

| UC | 유스케이스 | 정상 흐름 | 예외 |
|----|-----------|----------|------|
| UC-11 | 문의 질문 입력 | 고객이 자연어로 질문 입력 | 빈 입력 시 재입력 요청 |
| UC-12 | AI 답변 생성 | AIAdapter.ask() 호출 → AI 응답 수신 | API 오류 시 "잠시 후 다시 시도" 안내 |
| UC-13 | DB 대조 검증 | AI 답변과 DB 정보 비교 → 불일치 시 ⚠ 경고 + DB 기준 정보 병기 | 불일치 감지 → 보정 답변 제공 |

---

### 2-4. 마케팅 콘텐츠 생성 (F-04)

```
점주   ──► UC-14 홍보 문구 생성 요청
AI API ──► UC-15 AI 문구 생성  《include》UC-14
점주   ──► UC-16 채널 선택 및 포맷 적용  《include》UC-15
```

| UC | 유스케이스 | 정상 흐름 |
|----|-----------|----------|
| UC-14 | 홍보 문구 생성 요청 | 이벤트명·메뉴·할인율 입력 |
| UC-15 | AI 문구 생성 | AI API 호출 → 홍보 문구 초안 생성 |
| UC-16 | 채널 선택 및 포맷 적용 | SNS·블로그·카카오 중 선택 → Strategy 패턴으로 포맷 변환 → 최종 출력 |

| UC | 유스케이스 | 정상 흐름 | 예외 |
|----|-----------|----------|------|
| UC-17 | 채널별 홍보 문구 출력 | 채널 선택 → ChannelStrategy.format() → 결과 출력 | — |
| UC-18 | 포맷 규칙 검사 | 글자 수·이모지·해시태그 정책 자동 검사 | 규칙 위반 시 경고 메시지 출력 |

## 3. 유스케이스 관계 정리

| 관계 | 설명 | 예시 |
|------|------|------|
| **《include》** | 반드시 포함되는 기능 | UC-12(AI 답변) 는 UC-11(질문 입력) 을 포함 |
| **《extend》** | 선택적으로 확장되는 기능 | UC-13(DB 대조) 는 AI 불일치 시 확장 실행 |
